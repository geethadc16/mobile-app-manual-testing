# Mobile App Manual Testing Portfolio

## About This Project
This repository contains practical examples of manual testing for a fictional mobile application. It demonstrates my understanding of test scenarios, test case design, test execution, and defect reporting.

## Testing Scope
- Functional testing
- Smoke and sanity testing
- Regression testing
- Positive and negative testing
- Boundary value analysis
- Mobile UI and compatibility testing
- Defect reporting and retesting

## Application Under Test
**Sample application:** Telecom Mobile App

**Platform:** iOS and Android

**Sample features:**
- User login
- Account balance
- Mobile recharge
- Recharge history

*Note: This is a practice project using fictional application details and test data.*

## Repository Contents
- `test-scenarios/` — High-level testing scenarios
- `test-cases/` — Detailed test cases and expected results
- `bug-reports/` — Sample defect reports
- `test-execution/` — Sample execution results

## Objective
To demonstrate practical manual testing skills and continuously improve my QA knowledge through hands-on exercises.
